UI refresh + sound effects
==========================

- New colorful dark/light interface inspired by the supplied Smart Excel Toolkit theme.
- Static text has been shortened throughout the page.
- Added responsive cards, gradient title, animated backgrounds, hover states, button shimmer, upload animation and improved table styling.
- Added a sound toggle with lightweight Web Audio effects for hover, click, theme, drag/drop, generate, success, error and download actions.
- Sound is generated in the browser; no audio files are needed.
- Busy buttons now keep and restore their original icons correctly.
- All earlier report logic, reference Excel files, embedded mappings and tests remain included.

Counting logic retained
=======================

1. Enquiry -> Publisher
2. Registration -> User Name FEE when filled; otherwise Publisher
3. Admission -> User Name Token Fee when filled; otherwise Publisher

A counsellor can therefore receive Registration/Admission counts even when another Publisher created the enquiry.
